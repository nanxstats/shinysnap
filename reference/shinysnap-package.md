# shinysnap: Save and Restore the State of 'shiny' Applications

Take a snapshot of the state of a running 'shiny' application, the
current input values plus any server-side values you register, and write
it to a plain, human-readable JSON file that can be shared, kept under
version control, and hand-edited. Restore it later into a different
session without a page reload and without bookmarking. Restoring waits
for inputs rendered dynamically to appear, so no timing guesses are
needed, and reports which values were applied, which never appeared, and
which failed.
